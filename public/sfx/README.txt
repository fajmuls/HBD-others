Untuk menambahkan efek suara (Sound Effects), unggah file MP3 ke dalam folder `public/sfx/` dan beri nama sesuai daftar di bawah:
- `love-mode.mp3` : Suara saat toggle Love Mode dinyalakan (misal: suara saklar klik atau efek transisi magis).
- `tictactoe-click.mp3` : Suara saat mengklik kotak tic-tac-toe.
- `tictactoe-win.mp3` : Suara saat permainan tic-tac-toe dimenangkan.
- `page-flip.mp3` : Suara lembaran kertas/buku dibalik (untuk halaman Story).
- `blow.mp3` : Suara tiupan atau sorakan saat lilin berhasil ditiup.

Aplikasi akan otomatis memutar file-file ini jika tersedia. Jika file belum diunggah, tidak akan ada error.
